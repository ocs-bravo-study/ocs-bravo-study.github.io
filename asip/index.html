Score sheet · Communicate by Tactical Radio

    Measures 4–5 (radio check, 10–20 word message) are voice steps and are not part of this key drill.

    Exam mode

    • One clock for the whole drill: 5:00. It starts when you press Start.
    • No coach, no key highlights, no 7-second bar, no ✓ marks until the end.
    • Assemble the radio first, as you do in the real test: tap the battery, the antenna and the handset to put them on. No battery, no power. A part still missing at the end is a NO-GO.
    • The radio starts off. Set FCTN to load first; that turns it on. Mode SC, COMSEC PT and CHAN 1 can be set in any order; only the settings have to be right (mode and channel must be set before you load). Fastest: one pass through MENU, CHAN 1 → MODE SC → CMSC PT. Then for each of channels 1–3: Set CHAN → Press FREQ → Press CLR → Enter 5 digits → Press STO within 7 seconds. Then Set FCTN to SQ. ON. The grader gives you 1 of the 3 frequencies: set CHAN to that channel, and set power and volume to that setting. Using MENU before LD is an order error and a NO-GO. Any other slip can be fixed: go back (to LD if needed), correct it, and finish in SQ ON; only the final settings count.
    • Three channels (CH 1–3). The call frequency appears at step 3. The exam ends when the radio is set to communicate in SC mode, or at 5:00. A NO-GO sends you to Charlie Company.

    Cheat sheet · AN/PRC-119F (RT-1523E ASIP)

    Score-sheet steps and the keys for each

    1. Obtained required SC frequencies. The grader gives you 3 frequencies for 3 channels.
      • Assemble the radio (in the test you do this yourself): BB-2590 battery into the battery box, antenna onto the antenna connector, H-250 handset into AUD/DATA. Without the battery the radio is dead.
      • Prepare radio for Single Channel Frequencies loading.
      • Set FCTN to load: knob to LD.
      • Then one pass through MENU (VOL → CHAN → PWR → MODE → CMSC):
      • Set CHAN 1: MENU twice, press 1.
      • Set mode to SC: MENU twice (past PWR), CHG twice (FH → FHM → SC).
      • Set COMSEC to PT: MENU once, CHG 3 times (CT → TD → RV → PT).
      The radio starts off, at the TM defaults (CHAN not 1, PWR LO, MODE FH, COMSEC CT, VOL 5). Turning FCTN to LD turns it on. After LD, these three can be set in any order and only the settings count; following the MENU order is simply the fastest (5 MENU presses). Mode must be SC before you load, and CHAN must be the channel you are loading. Power and COMSEC don't affect loading. From the COMSEC screen you can press FREQ right away. Missed something, like CHAN 1? Go back (to LD if needed), fix it and load again; only the final settings count.
    2. Load SC frequencies.
      • Press FREQ: FREQ shows what the channel holds now.
      • Press CLR: CLR clears the display to -----.
      • Enter 5 digits SC frequencies: 81.000 is 81000.
      • Store SC frequencies. Press STO within 7 seconds: STO; the display blinks once.
      • Stored Channels 1-3: MENU twice → 2 and repeat, then MENU twice → 3 and repeat.
    3. Prepare to Communicate. The grader gives you 1 of the 3 frequencies to call the distant station.
      • Set FCTN to SQ. ON: knob to SQ ON.
      • Set CHAN to CHAN 1-3: MENU twice, then the channel that holds that frequency.
      • Set power and volume to that setting. Volume: MENU once, press the digit. Power: MENU to PWR, then CHG (LO → M → HI → PA; M is MED).
      • Communicate in SC Mode.

    Score-sheet settings, all Single Channel Plain Text. Setting 1: CH 1, 81.000, power HI, vol 8. Setting 2: CH 2, 55.000, power HI, vol 5. Setting 3: CH 3, 57.900, power MED, vol 6. In this trainer power and volume are radio-wide, so they are graded on the setting the grader calls.

    Steps 4–5 (radio check, 10–20 word message) are voice steps and are not drilled here. Standard: within 5 minutes, 100% accuracy.

    Notes

    MENU and CLR share one key. If no key is pressed for 7 seconds, the display times out and drops what you typed.

    FCTN knob: drag it, or tap its right half to turn clockwise and its left half counterclockwise. On a computer you can also type digits, F = FREQ, C or M = MENU/CLR, S = STO.
